# 清原山序｜一盒黄精的山林故事

用于“裕恒源黄精果礼盒”包装二维码的移动端数字故事页面。

**公开预览：** [https://jhg20070623-ai.github.io/qingyuan-shanxu-digital-story/](https://jhg20070623-ai.github.io/qingyuan-shanxu-digital-story/)

本项目使用原生 HTML、CSS 和 JavaScript，可作为静态网站部署，无数据库、外链字体或运行时服务依赖。

## 本地预览

在本目录运行：

```powershell
python -m http.server 4173
```

浏览器打开 `http://localhost:4173`。也可将本目录直接作为 Vercel、Cloudflare Pages 或 GitHub Pages 的静态站点根目录。

## 页面内容

- 清原地域关系示意、黄精植物与版画视觉、设计流程
- 按最终 V5.5 六袋 Master 顺序展示的可交互横向浏览：01/02 黄精根茎组、03/04 山林组、05/06 植物组
- 礼盒闭合/开启效果切换、绿色设计建议、扫码后的故事路径、品牌入口
- 手机菜单、键盘可用的六袋浏览、减少动态效果偏好支持

390 × 844 移动视口截图位于 `screenshots/`：首屏、清原地域、六袋系列、开盒展示和品牌入口。

## 配置

编辑 `js/config.js` 中的 `brandUrl` 和 `shopUrl` 接入已核实的品牌官网、官方店铺地址。任一地址留空时，页面显示“品牌入口待接入”或“官方购买入口待接入”。

`isDemo` 默认是 `true`。品牌链接、产品信息与企业确认内容接入并复核后，可按实际状态更新此值。

品牌官网与购买地址尚未接入，对应按钮会保持禁用提示状态。

## 视觉资产与事实边界

页面使用随参赛项目提供的裕恒源 Logo、V5.5 礼盒闭盒/开盒效果、六袋单袋稿、黄精版画和根茎视觉资产。六袋展示按 V5.5 最终稿编号，不另绘或生成包装。

页面中的礼盒与包装均标注为设计效果/方案展示。地域图只表达“辽宁—抚顺—清原”的概念关系，不表示精确行政边界或山脉坐标。页面不提供溯源、生产、检测、认证、医疗或保健功效声明。
